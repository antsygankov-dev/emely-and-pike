# State Diagram: СамоходныеСани

---

## 1. Краткое описание
Диаграмма состояний описывает возможные состояния и переходы объекта **СамоходныеСани** в системе "По Щучьему Велению". Сани могут находиться в состоянии ожидания (`Idle`) или движения (`Moving`), а также переходить между ними.

---

## 2. Состояния
   Состояние | Описание                          |
 |-----------|-----------------------------------|
 | `Idle`    | Сани находятся в состоянии покоя. |
 | `Moving`  | Сани движутся самостоятельно.     |

---

## 3. Переходы
 | Исходное состояние | Конечное состояние | Условие перехода               | Описание перехода                          |
 |--------------------|--------------------|--------------------------------|--------------------------------------------|
 | `[*]`              | `Idle`             | Инициализация                 | Начальное состояние после создания объекта. |
 | `Idle`             | `Moving`           | `selfDrivingSled()`           | Сани начинают движение после команды.      |
 | `Moving`           | `Idle`             | Остановка                     | Сани останавливаются по команде или условию. |

---

## 4. Диаграмма состояний
```plantuml
@startuml
state "СамоходныеСани" as Sled {
  [*] --> Idle
  Idle --> Moving: selfDrivingSled()
  Moving --> Idle: Остановка
}
@enduml
