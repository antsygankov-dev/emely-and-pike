# Class Diagram: По Щучьему Велению

---

## 1. Краткое описание
Диаграмма классов описывает взаимодействие между персонажами и объектами сказки "По Щучьему Велению". **Емеля** отправляет команды **Щуке**, которая управляет **Санями** и **Ведром**.

---

## 2. Классы

### 2.1 Класс: Емеля
- **Описание:** Главный герой сказки, который отправляет команды Щуке.
- **Атрибуты:** Нет явных атрибутов.
- **Методы:**
  - `отправляет команды(command: String)`: Отправляет команду Щуке для исполнения.

---

### 2.2 Класс: Щука
- **Описание:** Волшебная щука, исполняющая команды Емели.
- **Атрибуты:**
  - `Сани: Сани`: Объект саней, которым управляет Щука.
  - `Ведро: Ведро`: Объект ведра, которым управляет Щука.
- **Методы:**
  - `разобрать команду(command: String)`: Разбирает и исполняет команду от Емели.

---

### 2.3 Класс: Сани
- **Описание:** Волшебные сани, которые могут двигаться самостоятельно.
- **Атрибуты:**
  - `состояние: String`: Текущее состояние саней (например, "движутся", "остановлены").
- **Методы:**
  - `самоходные сани()`: Активирует режим самоходных саней.

---

### 2.4 Класс: Ведро
- **Описание:** Волшебное ведро, которое может выполнять действия автоматически.
- **Атрибуты:** Нет явных атрибутов.
- **Методы:**
  - `автоматическое Ведро()`: Активирует автоматический режим работы ведра.

---

## 3. Взаимодействие между классами
   Источник | Назначение | Описание взаимодействия |
 |----------|------------|-------------------------|
 | Емеля    | Щука       | Емеля отправляет команды Щуке для исполнения. |
 | Щука     | Сани       | Щука управляет санями, активируя их самоходный режим. |
 | Щука     | Ведро      | Щука управляет ведром, активируя его автоматический режим. |

---
