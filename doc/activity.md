# Activity Diagram: По Щучьему Велению

---

## 1. Краткое описание
Диаграмма активности описывает процесс выполнения команд, которые **Емеля** отправляет **Щуке**. В зависимости от типа команды, Щука активирует либо **Сани**, либо **Ведро**.

---

## 2. Основные шаги

### 2.1 Начало процесса
- **Действие:** Емеля даёт команду.
- **Описание:** Емеля формулирует и отправляет команду Щуке.

---

### 2.2 Разбор команды Щукой
- **Действие:** Разбор команды Щукой.
- **Описание:** Щука анализирует полученную команду и определяет, к какому объекту она относится.

---

### 2.3 Условное ветвление

#### 2.3.1 Команда для саней
- **Условие:** Команда предназначена для саней.
- **Действия:**
  1. **Вызов метода:** `Сани.СамоходныеСани()`
  2. **Результат:** Сани переходят в состояние "В движении".

#### 2.3.2 Команда для ведра
- **Условие:** Команда предназначена для ведра.
- **Действия:**
  1. **Вызов метода:** `Ведро.автоматическоеВедро()`
  2. **Результат:** Ведро переходит в состояние "Наполняется".

---

## 3. Диаграмма активности
```plantuml
@startuml Activity_ПоЩучьемуВелению

start
  :Емеля даёт команду;
  -> Разбор команды Щукой;

  if (Команда для саней?) then (Да)
    :Вызов Сани.СамоходныеСани();
    :Состояние: В движении;
  else (Нет)
    :Вызов Ведро.автоматическоеВедро();
    :Состояние: Наполняется;
  endif

  stop

@enduml
